## 出现国外手机号验证页面，应该怎么处理？

如果客户端登录过程中出现 Phone number required、Verify your phone number 等提示，可以先检查页面上有哪些验证选项。

有些页面默认选择美国区号 +1，但这不代表所有用户都必须使用美国号码。

需要注意，OpenAI 的手机号验证通常不能直接改成邮箱验证码，也不能用身份验证器中的动态验证码替代。

如果手机号码不受支持，或者一直无法完成验证，可以查看 OpenAI 官方帮助中心的说明，必要时联系官方客服。

不建议随便购买陌生人提供的一次性接码号码。后续如果账号再次触发验证，可能无法继续接收验证码，还会增加账号安全风险。
